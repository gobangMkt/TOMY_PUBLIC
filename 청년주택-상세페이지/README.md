# 청년주택 상세페이지 — 단독 배포 키트

고방 청년주택 지면 광고 상세페이지를 독립 파일로 뜯어낸 키트입니다. 이후 카피·디자인 관리를 달리아님이 직접 하도록 넘기는 용도.

## 설치 (Claude Code 사용자)
1. `청년주택-상세페이지.zip`을 원하는 폴더에 압축 해제
2. 그 폴더에서 Claude에게: **"README대로 배포해줘"**
3. 최초 1회 `vercel login`할 때만 브라우저 로그인이 필요하고, 나머지(배포·URL 반영·재배포)는 Claude가 이어서 진행

## 들어있는 것
- `product-youth.html` · `assets/`(style.css + 지면 스크린샷 6장)
- 자세한 배포 런북은 압축 해제한 폴더 안의 `README.md` 참고

## 주의
- 리드폼(상담신청)은 이미 코드에 연결되어 있어, 그대로 두면 기존 구글시트(admin)에 계속 쌓입니다. 코드의 `LEAD_ENDPOINT` 값은 건드리지 마세요.
- 배포하면 새 URL이 생깁니다 — 확정되면 노션 "청년주택 전달" 문서의 랜딩 링크를 교체해야 합니다.
