# UI/UX 핵심 기본 원칙 (통합본)

출처: 독립디 유튜브(2026-07-14) + 애플 공식 디자인 팁(2026-07-14, developer.apple.com/kr/design/tips) 통합·중복제거·충돌해소

## 1. 레퍼런스는 검증된 앱 기준으로
핀터레스트는 색감/무드용일 뿐 구조 참고는 부적합. 토스·당근·네이버페이 등 실사용 검증된 앱의 폰트·여백·버튼 배치를 벤치마킹.

## 2. 터치 대상 크기 — **최소 44×44pt** (애플 공식 기준 채택)
독립디 영상은 32px 최소를 언급했으나, 애플 HIG 공식 기준(44×44pt, 안드로이드 48dp와도 정합)이 더 신뢰도 높은 표준이라 이걸로 통일. 버튼 주변 여백도 충분히.

## 3. 텍스트 크기·줄간격
- 본문 최소 13pt, 안정적으로는 14~16pt. 12pt 이하 비추천 (애플 자체 최소 기준은 11pt지만 실사용 가독성 기준은 13pt 이상 권장).
- 줄간격은 폰트 크기의 1.4~1.6배 (제목류는 1.2배).

## 4. 대비 — **WCAG 4.5:1 이상**
텍스트-배경 명도 대비 WCAG 기준 4.5:1 이상 확보 (야외·저시력 사용자 고려). 애플 tips도 "명확한 대비" 언급하나 구체 수치는 WCAG 쪽이 실행 가능한 기준.

## 5. 정보 위계
크기·굵기·색상·여백을 조합해 최소 3단계 위계 부여. 텍스트를 다 같은 크기로 나열 금지, 글자 줄여서 해결하려 하지 말 것.

## 6. 아이콘·이미지 통일성
여러 소스에서 아이콘 섞어 쓰지 말고 하나의 세트로 통일(굵기·모서리·스타일 통일). 이미지도 톤·채도·색감 통일. 고해상도(@2x/@3x) 필수, 의도한 비율 유지(왜곡 금지).

## 7. 인터랙션 피드백
클릭 시 색 변화·로딩 스피너 등 명확한 반응 필수 — 없으면 사용자가 "멈췄다"고 오인.

## 8. 컬러 제한
메인 컬러 1~2개, 보조 컬러 3개 이내.

## 9. 여백·그루핑·정렬 — 게슈탈트 원리 4종 (2026-07-14 확장)
- **근접성**: 관련 요소는 가깝게, 무관한 요소는 멀게
- **유사성**: 비슷하게 생긴 요소는 같은 기능/그룹으로 인식됨 — 색상·형태 통일로 그룹 표현
- **연속성**: 요소가 일렬/곡선으로 배치되면 하나의 흐름으로 인식 — 시선 유도에 활용
- **폐쇄성**: 일부만 보여도 뇌가 완전한 형태로 채워 인식 — 아이콘·프레임 단순화에 활용

4/8배수 간격 시스템, 애매하면 넓히는 쪽 선택. 제어기는 그것이 수정하는 콘텐츠 가까이 배치. 텍스트·이미지·버튼 정렬로 연관성 표현.

## 10. 한 화면 = 한 행동
기능을 몰아넣지 말고 단계를 쪼개 한 번에 한 가지만 요구 (토스 원씽 폼 사례 — [[reference_toss_ux_psychology_laws]] 포스텔의 법칙과 동일 맥락).

## 11. 플랫폼 네이티브 패턴 준수
iOS(좌상단 뒤로가기)·안드로이드(하단 내비게이션) 등 플랫폼 고유 관습 따를 것. 웹서비스라도 모바일 사용자의 플랫폼 습관은 존중.

## 12. 콘텐츠 반응형
기기 화면에 맞는 레이아웃 — 확대/축소·가로 스크롤 없이 기본 콘텐츠가 다 보여야 함.

## 부록: 실기기 검증
작업 중간중간 실제 스마트폰(피그마 미러링 등)으로 반드시 미리보기 — 툴 화면과 체감 다름.
