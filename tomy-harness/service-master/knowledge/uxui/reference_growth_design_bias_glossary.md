# 인지편향·UX 법칙 글로서리 (growth.design 106개 중 신규분)

출처: https://growth.design/psychology (2026-07-14 수집)

⚠️ 중복 제외: Hick's Law·Fitts's Law·Miller's Law·Tesler's Law·Von Restorff Effect·Social Proof·Loss Aversion·Primacy&Recency(Serial Position Effect)·Law of Proximity/Similarity/Prägnanz(=근접성·유사성·폐쇄성)·Peak-End Rule·Aesthetic-Usability Effect는 기존 파일에 이미 있어 여기서 생략([[reference_toss_ux_psychology_laws]], [[reference_ui_ux_core_principles]], [[reference_super_expert_4_domains]] 참고).

## 🙈 정보 필터링
- **Confirmation Bias**: 자기 생각을 확인해주는 증거만 찾음
- **Priming**: 이전에 본 자극이 다음 결정에 영향
- **Cognitive Load**: 작업 완료에 드는 정신적 노력의 총량 ([[reference_ux_judgment_lenses]] 2번 렌즈와 동일 개념)
- **Anchoring Bias**: 처음 본 정보에 크게 의존
- **Nudge**: 미묘한 힌트로 결정에 영향
- **Progressive Disclosure**: 복잡한 기능을 단계적으로 노출 — 온보딩 설계 핵심 패턴
- **Banner Blindness**: 반복 노출된 요소는 무시당함 (배너·팝업 남용 경고)
- **Decoy Effect**: 버릴 선택지를 하나 끼워 다른 선택을 유도 — ⚠️설득기법, 가격표 설계 시 다크패턴 경계 검토
- **Framing**: 정보 제시 방식이 판단을 바꿈
- **Von Restorff류 확장 — Visual Hierarchy/Contrast/Signifiers/Juxtaposition**: 시각 위계·대비·단서·근접배치 — [[reference_ui_ux_core_principles]] 5·9번과 동일 맥락
- **Centre-Stage Effect**: 여러 옵션 중 가운데 것을 고르는 경향 — 가격 플랜 3단 구성 시 활용
- **Survivorship Bias**: 탈락한 데이터를 무시하는 경향 — 데이터 분석 시 주의([[reference_super_expert_4_domains]] 2번과 연결)

## 🔮 의미 추구
- **Scarcity**: 공급 제한 시 가치 상승 인식 — ⚠️"한정재고" 문구, 다크패턴 경계 검토
- **Curiosity Gap**: 정보 누락 시 궁금증 유발 — 클릭베이트와 한 끗 차이, 과용 주의
- **Mental Model**: 사용자가 이미 가진 작동방식 선입견 — 기존 패턴 무시하고 새로 만들면 혼란
- **Familiarity Bias**: 익숙한 경험 선호 — [[reference_ui_ux_core_principles]] 1번(검증된 앱 벤치마킹)과 동일 근거
- **Reciprocity**: 뭔가 받으면 보답하고 싶어짐 — 무료체험 설계 근거
- **Variable Reward**: 예측 불가능한 보상을 더 좋아함 — ⚠️SNS/게임 중독 설계의 핵심 기제, 습관형성 서비스에 쓸 때 윤리 경계 필수 검토
- **Aha! moment**: 신규 유저가 제품 가치를 처음 깨닫는 순간 — 온보딩 설계 핵심 KPI
- **Goal Gradient Effect**: 목표에 가까울수록 동기 상승 — 진행률 바·스탬프 적립 설계 근거
- **Occam's Razor**: 단순한 해법이 대개 더 나음
- **Noble Edge Effect**: 사회적 책임 있는 브랜드 선호
- **Miller's Law 확장 — Unit Bias**: 하나의 단위가 최적량으로 느껴짐 (1인분·1세트 판매 설계 근거)
- **Halo Effect**: 한 가지 특성으로 전체를 판단 — 첫인상(로딩화면·랜딩) 중요성 근거
- **Authority Bias**: 권위자 의견을 더 신뢰 — 전문가 인증·후기 배치 근거
- **Cognitive Dissonance**: 상충된 생각을 품는 게 고통스러움 — 구매 후 후회 방지 설계(구매 확인 메시지) 근거

## ⏰ 시간 제약
- **Labor Illusion**: 노력이 보일 때 더 가치있게 느낌 — 로딩 중 "분석 중입니다" 같은 과정 노출 근거
- **Default Bias**: 기존 설정을 안 바꾸려 함 — 기본값 설계가 전환율 좌우
- **Investment Loops**: 스스로 투자하면 재방문 가능성 상승 — 프로필 완성도·컬렉션 저장 기능 근거. 실전 검증 사례 → [[reference_tossbank_wow_moment_case]] ("지금 이자 받기" 능동 수령이 자동지급보다 더 큰 만족을 준 케이스)
- **IKEA Effect**: 자기가 직접 관여해서 만든/받은 것을 더 높이 평가 — 자동화가 늘 정답은 아니라는 근거, [[reference_tossbank_wow_moment_case]] 참고
- **Commitment & Consistency**: 이전 행동과 일관성 유지하려 함 — 작은 요청 → 큰 요청 순서 설계
- **Sunk Cost Effect**: 투자한 걸 빼기 싫어함 — 구독 해지 방해 UI에 악용되기 쉬움, ⚠️다크패턴 경계
- **Reactance**: 강요당한다고 느끼면 오히려 안 함 — 강제 회원가입 벽 설계 시 주의
- **Temptation Bundling**: 어려운 작업도 원하는 것과 묶으면 덜 힘듦
- **Discoverability**: 기능을 사용자가 발견할 수 있는 용이성 — 신규 기능 노출 설계 핵심 용어
- **Second-Order Effect**: 행동 결과의 결과 — UI 변경 시 2차 파급효과까지 검토

## 💾 기억
- **Provide Exit Points**: 적절한 순간에 이탈을 허용 — 억지로 붙잡지 않는 설계
- **Zeigarnik Effect**: 완료보다 미완료 작업을 더 잘 기억 — 프로그레스바 미완성 표시로 재방문 유도
- **Sensory Appeal**: 여러 감각을 자극하면 참여도 상승
- **Endowment Effect**: 자기 것이라 느끼면 더 가치있게 평가 — 커스터마이징·위시리스트 기능 근거
- **Chunking**: 그룹화된 정보를 더 잘 기억 — 전화번호 하이픈 표시 등
- **Delighters**: 예상 못 한 즐거운 경험을 잘 기억 — 이스터에그·감사 메시지
- **Internal/External Trigger**: 내적 기억 또는 외부 알림이 행동을 유도 — ⚠️Hooked 모델 핵심, 습관형성 설계 시 중독성 윤리 검토

## 실제 적용 사례 (원문 제공)
- Hick's Law: 넷플릭스 장르 필터링
- Fitts's Law: 모바일 버튼 하단 배치(엄지 접근성)
- Progressive Disclosure: 게임 튜토리얼 단계적 공개
- Social Proof: 아마존 리뷰·평점
- Scarcity: "한정 재고" 문구
- Reciprocity: 프리미엄 무료체험
- Default Bias: 자동갱신 구독 기본값
- Peak-End Rule: 앱 마지막 상호작용 긍정적 설계
- Chunking: 전화번호 구간 표시
