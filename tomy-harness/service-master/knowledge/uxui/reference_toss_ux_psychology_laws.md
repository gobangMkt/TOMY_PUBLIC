# 토스 앱의 UX 심리학 법칙 10가지

출처: https://brunch.co.kr/@mobiinside/4997 (2026-07-14 수집)

핵심: "대다수가 사용하기 편하다고 느끼는 서비스일수록 그 이면에는 여러 전문가들의 셀 수 없는 고민과 노력이 녹아있다"

| 법칙 | 내용 | 토스 적용 사례 |
|---|---|---|
| 제이콥의 법칙 | 사용자는 기존 경험으로 새 제품 판단 | 익숙한 금융앱 인터페이스 유지 |
| 피츠의 법칙 | 터치 거리·크기가 작업 시간 결정 | 적절한 객체 간격·버튼 크기 |
| 힉의 법칙 | 선택지 증가 시 인지 부하 증가 | 다단 구조로 정보 그룹핑 |
| 밀러의 법칙 | 사람은 7±2개 항목만 기억 가능 | 레이블별 객체 수 제한 |
| 포스텔의 법칙 | 사용자 입력 요청 최소화 | "1 thing / 1 page" 철학 |
| 피크엔드의 법칙 | 절정·마지막 경험이 전체 평가 좌우 | 실패 화면도 친근한 톤 |
| 테슬러의 법칙 | 필연적 복잡성은 줄일 수 없고 숨기거나 대신 처리 | 계좌번호 입력 시 은행 자동 추천 |
| 심미적 사용성 효과 | 아름다운 디자인이 더 쉬워 보임 | 캐주얼·둥근 디자인으로 거리감 제거 |
| 폰 레스토프 효과 | 비슷한 것 중 가장 색다른 것만 기억됨 | 강조색으로 신규 기능·알림 표시 |
| 도허티 임계 | 0.4초 내 피드백이 집중력 유지 | 로딩 시 애니메이션 제공 |

## 설계 원칙 요약
- 과도한 정보 제공 피하기
- 사용자 심리적 편안함 우선
- 복잡성은 뒤로 숨기고 단순함만 노출
- 애니메이션·메시지 톤 같은 미세한 순간까지 세심히 설계
