# 마케팅리드 지식 흡수 절차

사용자의 마케팅 어시스턴트에 이 폴더의 지식을 **더해서 키운다.** 어시스턴트를 교체하거나 기존 내용을 지우는 작업이 아니다.
설정 파일은 `~/.claude/shortform-review/config.md`다(없으면 SKILL.md "0-2"부터).

## 언제 하나
- 처음 설치할 때 한 번.
- 매번 릴스 기획·평가를 시작할 때 `MANIFEST.md`의 버전과 `config.md`의 "흡수한 버전"을 비교한다. 다르면 바뀐 파일만 다시 흡수한 뒤 본 작업을 한다.

## 절차
1. **어시스턴트 구조 파악:** `config.md`에 적힌 어시스턴트 위치에서 입구 파일(SKILL.md, CLAUDE.md, README.md 중 있는 것)과 지식 파일들이 어디에 어떤 형식으로 있는지 읽는다. 지식 폴더가 따로 없으면 그 어시스턴트 안에 `knowledge/marketing-lead/` 폴더를 만든다.
2. **파일별 대조:** `MANIFEST.md`의 파일마다 어시스턴트에 같은 주제가 이미 있는지 본다.
   - 없음: 어시스턴트의 파일 형식·이름 규칙에 맞춰 새 파일로 넣는다.
   - 있음, 내용이 겹침: 어시스턴트 쪽 파일에 빠진 절만 덧붙인다. 같은 말을 두 번 쓰지 않는다.
   - 있음, 내용이 충돌: 둘 다 남기고 충돌한 지점에 "출처가 다른 기준: A는 ~, B는 ~"로 표시한 뒤, 끝나고 사용자에게 알린다. 어느 쪽이 맞는지 임의로 정하지 않는다.
3. **기존 내용 보호:** 어시스턴트의 기존 문장을 지우거나 고쳐 쓰지 않는다. 덧붙이기와 새 파일만 한다.
4. **라우팅 연결:** 어시스턴트 입구 파일에 "상황별로 무엇을 읽나"가 있으면 이 폴더 `README.md`의 표를 합쳐 넣는다. 없으면 입구 파일 끝에 그 표를 한 절로 추가해, 어시스턴트가 상황마다 해당 파일을 찾아 읽게 한다.
5. **출처 기록:** 어시스턴트 안에 `marketing-lead-sources.md`를 두고 흡수한 버전, 날짜, 파일별 처리 결과(새로 넣음 / 덧붙임 / 충돌 표시)를 적는다.
6. **설정 갱신:** `config.md`의 "흡수한 버전"을 `MANIFEST.md`의 버전으로 바꾼다.
7. **보고:** 새로 넣은 파일 수, 덧붙인 절 수, 충돌 목록을 사용자에게 짧게 알린다.

## 하지 않는 것
- 어시스턴트 파일 삭제, 기존 문장 수정.
- 이 폴더(스킬 안)의 파일 수정. 업데이트 때 덮어써진다.
- 회사 실측 수치를 지식 파일에 적재하기.
