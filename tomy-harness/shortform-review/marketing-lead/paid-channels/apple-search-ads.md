# 애플 서치 애즈 (ASA)

> 출처: 개인 채널 운영 노트. 회사 실측 데이터는 제외, 세팅 절차·전략만.

## 계정·캠페인 생성

1. searchads.apple.com 접속 → Apple ID로 로그인 → 계정 생성(회사정보·결제정보 입력)
2. 캠페인 유형: **기본형(Basic, 자동운영·비추천)** vs **고급형(Advanced, 세부 타겟팅·입찰 가능·추천)**
3. 프로모션할 앱 선택(App Store 등록 앱) → 게재 국가/지역 설정

## 4가지 광고 지면 (캠페인 종류)

| 지면 | 노출 시점 | 특징 |
|---|---|---|
| Today Tab | 앱스토어 첫 진입 홈화면 | 입찰전략만 존재, 세부 광고설정 불가 |
| Search Tab | 'Search' 탭 누른 직후 | Suggested 리스트 최상단 노출 |
| **Search Result** | 특정 키워드 검색 시 | 흔히 말하는 ASA 본체, 키워드 세팅 필요 |
| Product Pages | 다른 앱 상세페이지 하단 | "함께 볼만한 앱" 영역에 노출 |

## 키워드 전략 (Search Result 기준)

- **매칭 방식**: 일치검색(Exact — 확실한 키워드는 필수 등록) / 확장검색(Broad) / Search Match(Apple AI 자동추천, 일치검색과 분리 운영 권장 — 자동추천 키워드는 따로 분석) / 제외키워드
- **기본 운영 전략**: 일치키워드(브랜드·카테고리·경쟁사 등 확실한 것 — 일치검색 사용) + 탐색키워드(놓치는 키워드 — 확장검색/Search Match로 발굴)
- **브랜드 캠페인과 일반 캠페인은 분리 운영**(브랜드 키워드는 따로 관리해야 방어·분석이 명확)

## 세팅 절차

1. **예산**: CPT(클릭당 비용, MAX 지출단위 설정 후 키워드별 조정) 기본 / CPA(목표 전환당비용)는 초기엔 노출 제한 위험 있어 비추천
2. **키워드 등록**: 앱 등록정보 기반 추천 키워드가 자동으로 뜸 → 대량 등록 가능하나 초반엔 기본 키워드만 설정 권장
3. **타겟팅**: 전체 타겟 노출 vs 특정 타겟(연령·성별·위치·신규/기존 사용자) 설정
4. **소재**: 별도 제작 없이 App Store 등록정보(아이콘·제목·설명)를 자동 활용(복수 등록정보 준비해두면 전략적으로 특정 페이지만 노출 가능)
5. **모니터링**: Apple 검토 승인 대기 → 노출수·탭률(TTR)·설치전환율·비용대비성과 확인 → 비효율 키워드 정리 + 신규 키워드 추가(주기적)

**고급 최적화 팁**: 브랜드/일반 캠페인 분리, Search Match·Exact Match 분리 운영, TTR 높은 키워드에 집중 투자, iOS 14+ ATT(앱 추적 투명성) 영향 고려해 성과 측정.

## ASA vs Google UAC 비교 (채널 선택 판단용)

| 항목 | ASA | Google UAC |
|---|---|---|
| 운영범위 | iOS 앱스토어 내부만 | 구글검색+유튜브+Play스토어+디스플레이 |
| OS | iOS 전용 | Android+iOS |
| 트래픽 볼륨 | 낮음 | 높음 |
| 자동최적화 | 없음(키워드 직접 운영) | AI 자동 최적화 |
| 운영난이도 | 높음 | 낮음 |

한국은 iOS 점유율이 낮고(Android 약 70%) 검색보다 소셜/바이럴 의존 다운로드 패턴이 강해 ASA 활용도가 구조적으로 낮다. 그럼에도 iOS 유저는 구매력·LTV가 높아 고급/프리미엄 앱엔 유리하고, 경쟁이 적어 CPA가 저렴할 수 있으며, 브랜드 키워드 방어 목적으로 유효하다 — **iOS 비중이 높은 서비스(금융 등)에 한해 검토 대상.**
