# 애플 광고 (Apple Ads, 옛 Apple Search Ads·ASA)

> 출처: 개인 채널 운영 노트(세팅 가이드·전략 문서·성과 추천 정리)와 공개 가이드 요약, 웹 조사(Apple Ads 공식 뉴스·도움말 중심, 아래 "2025~2026 변경" 절). 회사 실측 데이터는 제외, 세팅 절차·전략만. 입찰 금액은 시장·시점마다 달라 **비율 감각**만 옮겼다. 외국 데이터 기반 벤치마크는 자사 채널 대비 상대 비교에만 쓴다. 2025-04-14부터 공식 명칭은 **Apple Ads**다(계정·캠페인·과금은 그대로). 이 파일과 다른 파일의 "ASA"는 같은 매체를 가리킨다.

## 성과 진단 요점 (인사이트용)

- **퍼널 순서**로 진단한다: 노출 → 탭률(TTR) → 설치 전환율(CR) → 설치당 비용(CPA/CPI). 노출 없음 = 입찰가·승인·키워드·좁은 타겟팅. TTR 낮음 = 키워드·페이지 관련성. 탭 후 설치 낮음 = 스토어 페이지(ASO)나 커스텀 제품 페이지 불일치. CPA 높음 = 입찰·키워드 효율.
- **TTR은 단가에 영향을 주는 관련성 신호**다. TTR 높은 키워드에 예산을 모은다. 정체의 주원인은 소재 피로보다 **키워드 포화와 경쟁 입찰 상승**으로 본다[추정, 운영 노트 해석].
- **입찰은 두 갈래**다. ①키워드 입찰 직접 관리(Manage Bids): 최대 CPT만 조정, 3~4일 관찰 후 노출 없는 키워드만 소폭 인상, 옛 Target CPA 칸은 켜지 않는다(운영 노트). ②2026년 도입된 **전환수 최대화**(Maximize Conversions): 목표 CPA와 일 예산만 주면 검색어마다 자동 입찰, Search Match 필수, 일 예산은 하루 전환 5건 이상(목표 CPA의 약 5배), 판단은 2주 이상 돌린 뒤 주 단위 평균으로(공식). 예산이 그에 못 미치면 ①이 기본이다.
- 2026-03부터 검색 결과에 광고가 최상단 외 아래 자리에도 붙는다(iOS 26.2 이상, 위치 선택·위치별 입찰 불가, 공식). 같은 키워드에 광고가 2개까지 붙어 **TTR·CPT가 이전 기간과 달라질 수 있으니** 2026-03 전후를 한 기준선으로 비교하지 않는다. 한국 적용 시점은 계정 화면으로 확인.
- 키워드 단위 CPA 판단 전에 최소 탭 수를 정한다(공식 수치 없음). 경쟁사 키워드만 "설치당 비용이 기준을 확실히 넘으면 정지".
- 애플 대시보드는 **설치까지만** 신뢰한다. Apple Ads는 2025-04-10 AdAttributionKit에 등록돼 다른 매체와 같은 귀속 규칙으로 비교되고, 키워드 단위 귀속은 AdServices API가 계속 준다(공식).
- **한국 참고치**는 아래 "한국 벤치마크"를 본다. 업종별 한국 수치는 없어 자기 계정 추세 비교가 우선이고, 크게 벗어날 때 원인 점검의 출발점으로만 쓴다.
- **자기 잠식**: 수확(일치) 캠페인 키워드를 탐색 캠페인 제외 키워드(일치)로 넣지 않으면 비용이 샌다.

## 2025~2026 변경

- **명칭**: 2025-04-14 Apple Search Ads → Apple Ads. 검색 결과 한 자리로 시작했지만 이제 여러 지면을 판다는 이유. 계정·캠페인·과금 방식은 그대로 (공식·담당자: ads.apple.com/news "Apple Search Ads is now Apple Ads").
- **검색 결과 추가 지면**: 2025-12-17 발표, 2026-03-03 영국·일본부터 단계 적용, 3월 말까지 전 시장 확대 예정. 다운로드의 65%가 검색 결과 아래쪽에서 시작된다는 것이 애플의 설명이다. 검색 결과 캠페인은 새 위치에 자동으로 포함되고 위치를 고르거나 위치별로 입찰할 수 없으며, 키워드 입찰가와 관련성으로 경매한다. iOS·iPadOS 26.2 이상에서 보인다. 과금(CPT·CPI)과 광고 형식은 그대로 (공식·담당자: ads.apple.com/news 2025-12-17, 9to5Mac 2026-01-22, AppTweak 한국어 블로그). 위치별 성과 보고가 나오는지는 확인되지 않았다. 한국이 3월 일정에 포함됐는지는 명시 자료가 없다.
- **전환수 최대화(Maximize Conversions)**: 2026-02-25 발표, 검색 결과 캠페인 전용 입찰 전략. 목표 CPA(탭 후 설치 1건당)와 일 예산을 주면 자동 입찰이 검색어마다 실시간으로 입찰하고, Search Match로 설치 가능성이 높은 키워드를 우선한다. 자동 생성 광고그룹에서는 Search Match를 끌 수 없고 키워드 입찰도 직접 못 넣는다. 제외 키워드는 쓸 수 있다. 과금은 CPT. 월 지출 상한은 일 예산 × 30.4일이고 기회가 많은 날은 일 예산을 넘겨 쓴다. 목표 CPA는 언제든 바꿀 수 있지만 **최소 2주 돌린 뒤 바꾸라**고 하고, 목표는 주 단위 평균으로 맞춘다. 일 예산은 하루 전환 5건 이상이 나오게 잡는다 (공식·담당자: Apple Ads 도움말 "Use the Maximize Conversions bid strategy"·Best practices "Maximize Conversions").
  - 키워드 입찰 직접 관리 캠페인은 옛 CPA 목표 칸을 끈다. 전환수 최대화는 별도 전략이라 예산이 하루 5건을 받칠 때 탐색·카테고리 볼륨용으로 검토하고, 브랜드 방어·일치 수확은 키워드 입찰 직접 관리로 남긴다. 둘을 같은 키워드에 겹치면 자기 잠식이 생기니 제외 키워드로 나눈다 (실무자 판단: MobileAction 블로그도 정밀 통제가 필요한 팀은 Manage Bids를 유지하라고 함).
- **귀속**: 2025-04-10 Apple Ads가 AdAttributionKit에 등록됐다. 개발자는 AdAttributionKit에 등록된 다른 매체와 같은 귀속 로직으로 Apple Ads 성과를 나란히 볼 수 있다. AdServices API는 계속 유지된다 (공식·담당자: Apple Ads 도움말 "App ad attribution overview"). 같은 전환이 AdServices와 AdAttributionKit 양쪽에 잡히던 중복이 줄고, 브랜드 키워드 캠페인이 다른 매체의 마지막 터치를 가져갈 수 있다는 지적이 있다 (실무자).
- **커스텀 제품 페이지(CPP)**: 앱당 35개에서 70개로 확대(2025-10-29). 2025-07부터 CPP에 키워드를 배정해 오가닉 검색에도 띄울 수 있다(키워드 색인 자체가 늘지는 않음). 모든 CPP를 Apple Ads 광고 변형에 쓸 수 있다 (실무자: MobileAction·Adapty·Sonar 블로그. 애플 원문 미확인). CPP는 앱 심사를 거친다.
- **자체 소재 업로드(예정)**: WWDC 2026(2026-06-08 발표)에서 App Store Connect '애셋 라이브러리'에 전용 이미지·영상을 올려 Today 탭과 검색 결과 광고, 제품 페이지 헤더·오가닉 검색 결과에 쓸 수 있게 한다고 했다. 3:2 비율, 영상 5~30초(검색 결과 광고에서만), 소리는 재생되지 않고 이미지 안 텍스트는 허용·현지화 가능, 앱 제출 없이 올리되 Apple Ads 심사 후 게재. 2026-09-26 기준 도움말은 아직 "올가을 제공 예정" (공식·담당자: ads.apple.com/news 2026-06-08, Apple Ads 도움말 "Design your own ads with creative assets", SplitMetrics 2026-09).
- **한국 벤치마크** (컨설팅: AppTweak "Apple Ads 벤치마크" 한국어판, 2026-08-19 게시, 2025년 앱 약 3,500개·캠페인 5만 개·광고비 10억 달러 규모의 자사 관리 데이터): 대한민국 검색 결과 CPI 1.84달러, TTR 6.30%, 탭 후 설치율 51%, CPM 48.11달러. 지면별 설치율은 Search 탭 19%, Today 탭 11%, 제품 페이지 12%. 한국 카테고리별 수치는 없다(카테고리 표는 미국 기준, 라이프스타일 CPI 3.45달러·설치율 52%, 유틸리티 CPI 2.90달러·설치율 58%). 대행 툴 고객 계정 평균이라 업종·브랜드 인지도 차이가 섞여 있다.
- **기타**: 2026-03-17 계정 전체 데이터를 탐색하는 'Insights' 분석 기능, 2026-08-21 Apple Maps 광고(미국·캐나다 한정) 출시 (공식·담당자: ads.apple.com/news).

### 소재(CPP) 운영과 하지 말 것

- 키워드군마다 그 검색 의도에 맞는 CPP를 붙인다(예: "고시원" 검색에는 고시원 목록 화면이 첫 스크린샷인 페이지). 탭 후 설치율이 낮은 키워드군은 입찰보다 CPP 불일치를 먼저 의심한다.
- 스크린샷·미리보기 영상은 실제 앱 화면이어야 한다. 앱에 없는 기능·가격·혜택을 보여 주는 메타데이터는 앱 심사 지침의 정확한 메타데이터 조항으로 반려된다 (공식·담당자: App Store 심사 지침 2.3). 자체 소재 업로드가 열려도 Apple Ads 심사를 따로 거친다.
- 소재 피로 지표보다 **키워드별 TTR 추세**와 **CPP별 탭 후 설치율**이 교체 판단 기준이다.

## 계정·캠페인 생성

1. searchads.apple.com 접속 → Apple ID로 로그인 → 계정 생성(회사정보·결제정보). 카드 선등록 후 소진분 청구, 인보이스 청구는 애플과 협의.
2. **베이직 vs 어드밴스드**: 베이직=설치당 과금(CPI), 앱당 월 상한 있음, 신규 계정 크레딧, 약정 없음, 키워드·오디언스 세분화 불가에 최적화 불투명, 어트리뷰션 API 제한. 어드밴스드=탭당 과금(CPT), 광고 그룹·키워드·타겟·예산·일정·소재·맞춤 보고를 직접 제어, 4개 지면 선택. **첫 설치 테스트용 소액 검증이 아니면 어드밴스드**(베이직은 무엇이 효과였는지 알 수 없어 학습 자산이 안 쌓인다).
3. 프로모션할 앱 선택(App Store 등록 앱) → 게재 국가/지역.

## 4가지 광고 지면

| 지면 | 노출 시점 | 특징 |
|---|---|---|
| Today Tab | 앱스토어 첫 진입 홈 | 입찰전략만 존재, 세부 설정 불가 (인지·볼륨용) |
| Search Tab | 'Search' 탭 진입 직후 | Suggested 리스트 최상단 (인지·볼륨용) |

| Product Pages | 다른 앱 상세 하단 | "함께 볼만한 앱" 영역, 경쟁사 앱 유저 탈환용 |

## 경매·과금 원리

- 키워드 검색 시 경매가 열리고 낙찰 광고가 결과 최상단에 파란 배경으로 노출된다. 과금은 최고입찰가가 아니라 **차순위 입찰가 기준**이라 입찰가를 높게 걸어도 그 금액이 곧바로 나가지는 않는다.
- 관련성(탭률)이 높으면 낮은 단가로도 상단을 확보한다. 반대로 남의 브랜드를 검색한 유저는 우리 광고를 누를 확률이 낮아 단가가 비싸진다.
- 소재는 별도 제작 없이 앱 메타데이터로 만든 네이티브 형태다. **커스텀 제품 페이지**(복수 등록정보)를 키워드군별로 붙이는 것이 소재 최적화의 사실상 유일한 레버.

## 캠페인 구조 (4분할)와 매칭 역할

- **브랜드(자사 키워드, 방어) / 카테고리 / 경쟁사 / 디스커버리(탐색)**로 쪼갠다. 한 광고 그룹에 섞으면 성과 분석과 예산 통제가 불가능하다.
- **디스커버리** 광고 그룹 2개: (a) 확장 검색 그룹(기존 키워드를 확장 검색으로, Search Match 끔) (b) Search Match 그룹(키워드 없이 Search Match만 켬). 브랜드·카테고리·경쟁사의 모든 키워드를 디스커버리의 제외 키워드(일치)로 등록한다.
- **Search Match는 탐색 캠페인에서만 켜고, 수확(일치) 캠페인에서는 끈다.**- 매칭 역할: Search Match = 그물(AI 판단, 사후 제외 키워드로만 통제), 확장 검색 = 미끼(핵심 단어 기준 확장), **일치 = 작살**(제어 최상, 단가·성과 측정이 깨끗). 일치를 따로 두는 이유: 황금 키워드 별도 입찰, AI가 더 싼 단어로 돌리며 핵심 키워드를 안 쓰는 간섭 방지, 키워드별 순수 성과 측정.

| 유형 | 매칭 | Search Match | 상대 입찰 수준 | 논리 |
|---|---|---|---|---|
| 브랜드 방어 | 일치 | OFF | 최저 | 자사 검색은 관련성이 최대라 알고리즘이 상단 배치, 경쟁사가 높게 불러도 낮게 방어 가능 |
| 롱테일 수확 | 일치 | OFF | 최저 | 경쟁 없는 독점 영역 |
| 카테고리/맞춤 수확 | 일치 | OFF | 중간 | 대형 경쟁자와 겹치는 격전지, 낮게 시작해 노출·TTR 보며 조정 |
| 경쟁사 | 일치 | OFF | 중상(상한 타이트) | TTR 낮고 단가 페널티, 설치당 비용이 한도 초과면 중단 |
| 탐색 | 확장 | ON | 중간 | 너무 낮으면 탐색이 안 나가고 너무 높으면 소진 |

## 주간 운영 루틴 ("무한 동력")

탐색 캠페인(씨앗 키워드 약 15개 확장 검색 + Search Match ON) → **매주 Search Terms 리포트 확인(약 15분)** → 비용만 쓰고 설치가 없는 검색어는 제외 키워드로 차단, 설치가 잘 된 검색어는 수확 캠페인에 일치로 이식. 이 루프가 롱테일을 자동 발굴한다. 검색어 리포트는 기간을 넓게 잡고, 제외 키워드는 캠페인 단위·일치 매치로 추가하는 편이 관리하기 쉽다. 키워드 중복 오류가 나면 목록을 비우고 한 번에 다시 붙여 넣은 뒤 일괄 적용.

## 세팅 절차

1. **예산**: CPT 기본(MAX 지출 단위 설정 후 키워드별 조정). 키워드 입찰 직접 관리 캠페인의 CPA 목표 칸은 끈다. 2026년 도입된 전환수 최대화 전략은 별개다(위 절).
2. **키워드 등록**: 앱 등록정보 기반 추천 키워드가 뜸. 초반엔 기본 키워드만.
3. **타겟팅**: 전체 vs 특정(연령·성별·위치·신규/기존 사용자).
4. **소재**: App Store 등록정보(아이콘·제목·설명) 자동 활용, 복수 등록정보를 준비해 두면 특정 페이지만 노출 가능.
5. **모니터링**: Apple 검토 승인 → 노출수·TTR·설치 전환율·비용 대비 성과 → 비효율 키워드 정리와 신규 키워드 추가(주기적).

## ASA vs Google UAC (채널 선택 판단용)

ASA는 iOS 앱스토어 안, 구글 앱 캠페인은 검색·유튜브·Play스토어·디스플레이를 덮는다. 구글은 트래픽 볼륨이 크고 자동 최적화가 기본이고, ASA는 볼륨이 낮고 키워드 직접 운영이 기본이다(전환수 최대화는 예외).

한국은 iOS 비중이 소수라(원문마다 20~30% 안팎으로 달라 집행 전 확인) 검색보다 소셜·바이럴 의존 다운로드가 강해 ASA 활용도가 구조적으로 낮다. 그럼에도 iOS 유저의 구매력·LTV, 낮은 경쟁 키워드의 CPA, 브랜드 키워드 방어 목적으로 유효하다. 구글 담당자 설명대로 구글 지면에서 iOS 설치가 거의 안 나간다면 **iOS 설치를 늘리려면 구글이 아니라 ASA를 검토**하는 것이 정합적이다.
