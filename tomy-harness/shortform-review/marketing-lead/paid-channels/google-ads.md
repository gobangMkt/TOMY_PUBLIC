# 구글애즈 (GDN·Pmax·유튜브)

> 출처: 개인 채널 운영 노트. 회사 실측 데이터는 제외, 세팅 절차·규격·원칙만.

## GDN 반응형 디스플레이 광고

Google AI가 이미지·로고·텍스트 소재를 조합해 각 지면에 맞는 광고를 자동 생성. 반응형을 함께 세팅하면 90% 더 많은 전환 확보 가능(구글 발표치).

**세팅 절차**: 캠페인 → 광고 → `+` → 반응형 이미지 광고 → 광고그룹 선택 → 랜딩URL·이미지·로고·제목/설명 입력 → 저장. **다양한 종류의 애셋(이미지·동영상·텍스트)을 골고루 쓸 것.**

**소재 규격(2024 기준)**:
| 구분 | 비율 | 권장크기 | 최소크기 | 최대이미지수 |
|---|---|---|---|---|
| 가로형 | 1.91:1 | 1200×628 | 600×314 | 15개 |
| 정사각형 | 1:1 | 1200×1200 | 300×300 | 15개 |
| 세로형 | 9:16 | 900×1600 | 600×1067 | 15개 |

로고: 가로형(4:1) 1200×300, 정사각형(1:1) 1200×1200, 최대 5,120KB. 이미지/로고 최대 5MB(JPG/PNG/GIF), 동영상 최대 15초·100MB(MP4/MOV, 유튜브 업로드 후 사용).
텍스트: 제목 최대 5개(한글 15자 이하), 설명 최대 5개(한글 45자 이하), 긴 제목 1개(한글 45자 이하) — 핵심 키워드 넣고 CTA 명확히.

**소재 제작 주의**: 이미지 테두리 금지 / 광고 텍스트 비율 20% 이하 권장 / 유사 이미지 여러개 금지 / CTA 버튼보다 텍스트로 강조 추천.

**최적화**: 성과 낮은 애셋은 바로 삭제 말고 새 애셋 준비되면 교체 / 최소 2주 학습기간 확보 후 분석 / 정기 리뷰 / A/B 테스트(복수 반응형 소재 동시 운영 비교) / CTR·전환율·노출수 등 다지표로 평가.

## 퍼포먼스맥스(Pmax) — 실적 최대화 캠페인

하나의 캠페인으로 검색·유튜브·디스플레이·디스커버·Gmail·지도까지 노출, 머신러닝이 입찰·소재를 자동 최적화(평균 13% 추가 전환).

**언제 쓰나**: 기존 캠페인 외 추가 전환 확보하고 싶을 때 / 다양한 지면 노출 원할 때 / 데이터분석 시간 부족할 때.
**주의**: 단독 운영보다 검색 캠페인과 병행 권장 / 사전에 충분한 전환 데이터 필요(없으면 저조) / 노출 지면 투명성 낮음(소재별 성과는 "높음/낮음" 정도만 확인 가능).

**세팅 7단계**:
1. **전환 설정** — 목표>전환에서 전환 액션·가치 사전 설정(중요도별 가치 차등, 기존 전환 그대로 재사용 권장)
2. **캠페인 생성** — 목표(판매/리드/목표없음) 중 1개 선택 → 관련 전환 목표 선택 → 캠페인유형 '실적최대화' 선택 → (커머스면) GMC 계정 연결
3. **입찰전략** — 전환선택="전환수 최대화" / 타겟CPA 설정="타겟 CPA" / 전환가치선택="전환가치 극대화" / 타겟ROAS 설정="타겟 ROAS". **입찰전략·예산 변경은 최소 1주 간격 유지**(학습에 중요한 정보라 자주 바꾸면 학습이 리셋됨)
4. **세부설정** — 노출 위치·언어 설정 + **최종 URL 확장 활성화 권장**(머신러닝이 최적 랜딩페이지를 스스로 찾음, 제외하고 싶은 페이지만 규칙으로 배제)
5. **애셋 그룹** — 제품/서비스 테마·타겟별로 여러 그룹 생성 가능. 텍스트(제목 최대15·긴제목5·설명5), 이미지(최대20, 가로/정사각/세로 모두), 동영상(10초+, 최대5개, 필수아님이나 강력 권장), 사이트링크·콜아웃 등 확장애셋 추가. **소재는 최대한 다양하고 많이 — 시스템이 조합해 최적 성과를 찾는다.**
6. **잠재고객 신호** — 검색테마(핵심 검색어 최대25개, 이미 검색광고 운영중이면 전환 발생 키워드 참고), 내 데이터(고객 구매이력·웹사이트 방문자 목록, 최근 유튜브 시청자 세그먼트), 관심분야/구매의도/인구통계, 맞춤 관심분야(유사 URL·유사 앱)
7. **예산 설정** — 신규 캠페인은 목표 CPA의 최소 20배 이상, 기존 캠페인 전환이면 최근 30일 평균 CPA의 최소 15배 이상으로 시작(학습 데이터 확보 목적)

**URL 확장 팁**: 방문페이지별 전환데이터를 통계및보고서>보고서에디터>템플릿갤러리에서 확인 → 전환율 높은 페이지는 유사 페이지 추가 제작, 낮은 페이지는 로딩속도·UX·CTA 위치 개선. 트래픽을 특정 페이지로만 제한하려면 URL 확장 대신 "페이지 피드"(CSV/Sheet로 원하는 랜딩페이지 목록만 업로드) 활용. 단일 제품/서비스만 파는 기업이나 랜딩페이지 구조가 단순한 기업은 URL 확장이 오히려 안 맞을 수 있음.

**성과 확인**: 세팅/변경 후 최소 2주는 학습기간, 그 이후 확인. 애셋그룹별 실적에서 '낮음' 소재는 바로 삭제 말고 대체 소재 준비되면 교체, 2~3주 간격으로 재확인.

## 유튜브 광고(YouTube Ads)

- **예산 구간별 성격**: 월 30만~300만원(소액, 성과 없이 끝날 가능성 높음) / 300만~1000만원 / 1000만~5000만원 / 5000만~억단위. **월 300만원 이상부터 유의미한 성과 기대 가능한 매체.**
- 비타민형(대중 상대)·진통제형(타겟 광고) 둘 다 가능. 목적: 인지/노출/유입.
- 브랜딩 캠페인·앱 다운로드 캠페인에 활발히 활용. **지면에 대한 이해를 바탕으로 지면 맞춤 영상 소재를 다량 생산해야** 최고 성과.

## Apple Search Ads(ASA) vs Google UAC — 왜 한국은 ASA를 잘 안 쓰는가

한국 시장에서 ASA 활용도가 낮은 구조적 이유(마케팅 채널 믹스 결정 시 참고):
- 한국은 Android 점유율(약 70%)이 높아 iOS 앱스토어 검색 시장 자체가 작음(반대로 미국·일본·영국은 ASA가 강력한 채널)
- 한국 유저는 앱 다운로드 시 앱스토어 검색보다 소셜미디어·바이럴에 의존하는 경향이 큼
- Google UAC는 검색+유튜브+디스플레이+Play스토어까지 커버(Android/iOS 모두), ASA는 iOS 앱스토어 내부로 한정
- ASA는 AI 자동최적화가 약해 키워드·입찰을 직접 운영해야 함(운영 난이도↑) — Google UAC 대비 다루는 마케터도 적음

**그래도 ASA를 쓸 이유**: iOS 유저는 구매력·LTV가 높아 고급 서비스 앱에 유리 / 경쟁이 적어 특정 키워드 CPA가 오히려 저렴할 수 있음 / 브랜드 키워드 방어(경쟁사가 내 브랜드 키워드 구매 시 대응) / ASO(앱스토어최적화)와 병행하면 검색순위 개선 효과. (세부 세팅 방법은 `apple-search-ads.md` 참고)
