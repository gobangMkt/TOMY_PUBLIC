# 메타 (인스타그램 + 페이스북)

> 출처: 개인 채널 운영 노트. 회사 실측 데이터·계정명은 제외, 세팅 절차·전략·용어만.

## 기본 구조

캠페인(목적 선택) → 광고세트(타겟·예산·노출위치를 묶는 실제 운영 단위) → 광고(실제 소재="크리에이티브").

- **인스턴트 경험**: 광고 클릭 시 별도 페이지 제작 없이 뜨는 즉석 랜딩 형식.
- **다이나믹 크리에이티브**: 이미지·문구 여러 개를 던져주면 메타가 알아서 조합해 만들어줌. 장점=조합 고민 불필요·한 캠페인에 광고 10개까지 편하게 생성. 단점=광고별 개별 성과 ID를 못 얻음(이미지×문구 조합이 다 섞여서 하나의 광고로 집계) — 이미지·문구 매치가 중요한 소재엔 안 맞음.
- **노출위치**: 마케팅목표≠캠페인목표이거나, 최적화를 기대하기 어렵거나, 특정 지면만 의도적으로 노리는 경우가 아니면 **자동 노출위치(수동 설정 안 함)가 효과적**.
- **참여(Engagement)**: 공유·공감·저장·댓글·페이지좋아요·반응·3초+동영상재생·사진조회·링크클릭을 모두 포함하는 지표.

## 캠페인/광고세트/광고 세팅 체크리스트

**캠페인**: 이름 규칙에 맞게 설정 + 목표(처음 정한 대로 유지 권장). A/B테스트·어드밴티지 캠페인예산은 선택사항(소재 A/B는 다이나믹크리에이티브로 이미 되므로 광고세트 단위 A/B는 안 해도 됨).

**광고세트**: 전환위치=웹사이트 권장 / 성과목표=링크클릭수 최대 권장 / 다이나믹크리에이티브=사용 권장 / 예산·일정 설정 / 타겟관리는 위치 지정할 때만 사용 / **어드밴티지+ 타겟에서 "타겟 추천"으로 맞춤타겟 선택, 상세타게팅은 안 함** / 노출위치는 기본값(자동) 유지.

**광고**: 이름 규칙 적용 / **집행 계정을 소재 성격별로 나눠 운영**(어그로성 강한 소재는 서브/체험형 계정, 브랜딩·일반 소재는 메인 브랜드 계정 — 소재 톤과 계정 페르소나를 맞추는 것이 핵심) / 광고 크리에이티브(이미지·영상·텍스트) 등록 / 랜딩페이지 URL에 UTM 파라미터 필수 부착.

## 메타 그로스 방법론 (A/B → 승격)

1. 소구점을 뽑아 소재를 만들고 **광고세트 단위로 A/B 테스트** 진행(하나의 광고세트 = 일부 변수만 다른 소재 묶음)
2. 효율 좋은 세트를 발견하면 → **그 세트를 복사해 새 테스트 세트를 만들고, 기존 이긴 세트는 그대로 둔 채 예산만 증액해 메인 세트로 승격**. ⚠️ 이긴 세트를 건드려서 새로 파면 메타 AI가 학습을 처음부터 다시 해서 오히려 효율이 나빠질 수 있다.
3. 광고세트 설정값(타겟·노출위치 등) 자체를 A/B 하고 싶으면 메타가 제공하는 정식 A/B 테스트 기능을 쓴다(노출 중복 없이 동일 예산·동일 타깃으로 공정 비교해줌).

## 효과적으로 작동시키는 법

- **타겟 믹스**: 자사 데이터로 맞춤(리타겟팅)·유사(Lookalike) 타겟을 얼마나 정교하게 만드는지가 실력 — 이게 고객 DB의 가치를 결정한다. 영상광고 시청자만 모아 타겟을 만들 수도 있음.
- **광고보고서**: CPC·CPM 등 핵심 수치를 주기적으로 그래프화해 페이드 마케팅 현황을 진단.
- **픽셀**: 서비스 내 이벤트 추적(단, 100% 정확치는 않음 — 이벤트관리자 PV값을 실데이터와 비교해 오차 확인 필요). 특정 이벤트를 "맞춤 전환"으로 등록하면 그 전환 자체를 목적으로 하는 캠페인 운영이 가능해짐.

## 맞춤 타겟 5종 (리타겟팅 원료)

웹사이트 방문자 / 장바구니 이탈자(구매 안 한 사람에게 리마인드) / 이메일 구독자 / 구매 이력 고객(재구매 유도가 신규유치보다 비용효율적) / 앱 사용자.

**리마케팅 세팅 5단계**: ①메타 픽셀 생성·설치(이벤트관리자→픽셀→웹 선택→코드를 HTML 헤더에 삽입) ②맞춤타겟 생성(타겟→맞춤타겟→웹사이트 소스→방문조건 설정, 예: "최근 30일 특정 페이지 방문자") ③캠페인 생성(목표="전환") ④광고세트에서 방금 만든 맞춤타겟 선택 + 예산·일정 설정 ⑤소재 등록 후 게시.

**타겟팅 장단점**: 장점=정밀 타겟팅·재타겟팅으로 전환율↑·유사타겟으로 신규고객 확장. 단점=개인정보 규제 이슈(GDPR·CCPA 등 고려), 타겟이 좁을수록 광고비 상승, 타겟이 너무 작으면 도달 자체가 부족해질 수 있음.

## 소재 기획 템플릿 구조

소재 기획은 다음 틀로 정리한다: **①이 기능/USP가 무엇인지 한 줄 정의 → ②왜 USP인가(고객이 어떤 불편을 겪는지 구체적으로 가시화·공감 메시지화) → ③이 소재로 강조할 포인트 2~3개.** USP는 반드시 "고객의 불편함"에서 역산해서 뽑아야 공감형 카피가 나온다(기능 자랑이 아니라 불편 해소로 프레이밍).
