# shortform-review: 릴스 기획·평가 스킬

인스타 릴스 레퍼런스를 모아 정리하고, 그걸로 릴스를 기획하고, 팀원·서포터즈가 만든 릴스를 평가하는 Claude Code 스킬입니다.
- 공통 판단 기준: 외부 릴스를 분석해 쌓은 목적별 템플릿, 기본기, 엣지, 버릴 것
- 내 레퍼런스: 마케팅할 주제마다 직접 모은 릴스 분석과 정리. 기획할 때 가장 먼저 씁니다
- 마케팅 판단: **본인 마케팅 어시스턴트**가 맡습니다. 스킬에 든 마케팅리드 지식(소재·카피·타겟팅·채널·예산·이벤트·상세페이지)을 그 어시스턴트에 더해서 키웁니다.

## 설치 (한 번만)
Claude Code 채팅창에 아래를 **그대로 붙여넣으면** 설치, 도구 준비, 마케팅 어시스턴트 연결까지 Claude가 진행합니다.

```
아래 순서대로 진행해줘.
1. 터미널에서 `npx skills add gobangMkt/TOMY_PUBLIC --skill shortform-review -g` 실행
2. 설치된 shortform-review 스킬의 SKILL.md를 읽고 "0. 처음 한 번: 설치 마무리"를 끝까지 진행
   (도구 설치는 묻지 말고 진행, 마케팅 어시스턴트 위치만 나한테 물어봐)
3. 다 되면 설치 결과, 마케팅 어시스턴트에 더해진 내용, 내가 쓸 수 있는 요청 예시 3개를 알려줘
```

중간에 한 번 **본인 마케팅 어시스턴트가 어디 있는지**(폴더 경로 또는 스킬 이름) 묻습니다. 알려주시면 마케팅리드 지식을 거기에 더합니다. 기존 내용은 지우거나 고치지 않고 덧붙이기만 하고, 겹치거나 기준이 다른 곳은 따로 알려드립니다.

설치 후 Claude Code를 한 번 껐다 켜면 스킬이 뜹니다(`/skills`로 확인).

## 쓰는 법
| 하고 싶은 것 | 이렇게 말하면 됩니다 | 받는 것 |
|---|---|---|
| 레퍼런스 수집 | `청년주택 레퍼런스로 쌓아줘` + 릴스 링크 여러 개 (알면 조회수·팔로워) | 릴스별 분석 저장 + 주제 정리 파일(먹힌 구성, 안 먹힌 것, 기획에 쓸 점) 갱신 |
| 만든 릴스 평가 | `이 릴스 평가해줘 https://www.instagram.com/reel/XXXX/ (조회 3.2만, 팔로워 1.1만)` | 목적·템플릿 판정, 통과·보완·재작업, 고칠 구간(초)과 방법, 다음에 얹을 엣지 |
| 서포터즈 릴스 일괄 평가 | `서포터즈 릴스들 평가해줘` + 링크 목록 + (알면) 계정별 팔로워·조회수 | 건별 평가 + 공통 문제 표 |
| 릴스 기획 | `청년주택 마케팅할 건데, 유입 목적 릴스 기획해줘` | 그 주제 레퍼런스를 근거로 템플릿 1~3개, 초 단위 구간 구성과 문구 초안, 얹을 엣지, 성공 지표 |
| 계정 짝 비교 | `OO 계정 짝 비교해줘 https://www.instagram.com/OO/` | 같은 계정 안 조회 상위 3·하위 3을 비교해 무엇이 갈랐는지, 계정 분석 파일 저장 |
| 운영 계정 관리 | `청년주택 계정 릴스 기획해줘`, `이 릴스 성과 기록해줘 + 링크 + 조회수 + 팔로워`, `이 계정 지난 달 정리해줘` | 계정별 프로필·운영 로그에 자동 기록, 계정 기준선 대비 판정, 월간 정리 |
| 서포터즈 챌린지 | `청년주택 서포터즈 챌린지 템플릿 만들어줘` | 템플릿 3~5개와 근거 두께, 올라온 릴스 일괄 평가 |
| 트렌드 | `요즘 릴스 뭐가 떠?` | 기준에 쌓인 엣지가 언제부터 퍼졌는지 |
| 어시스턴트 변경 | `마케팅 어시스턴트 다시 지정해줘` | 새 어시스턴트 연결 + 지식 흡수 |

조회수·팔로워 수는 링크로는 안 읽힙니다. 알면 같이 적어 주세요. 없으면 "미확인"으로 처리합니다.

**레퍼런스부터 모으세요.** 주제 레퍼런스가 없으면 공통 기준으로만 기획해서 정확도가 떨어집니다. 같은 업종·타깃 계정의 프로필 릴스 탭에서 조회수가 팔로워보다 크게 나온 것 위주로, 같은 계정에서 안 된 것도 1~2개 섞어 많을수록 정확해집니다.

## 목적 세 가지
| 목적 | 노리는 것 | 판단 지표 |
|---|---|---|
| 바이럴 | 조회수가 터지는 것 (공유·저장·반복 재생) | 팔로워 대비 조회수, 공유 |
| 유입 | 인스타 밖으로 넘어오는 것 (댓글 → DM 링크, 프로필 링크, 검색) | 댓글÷좋아요, 링크 클릭 |
| 구독 | 계정을 따라오게 하는 것 (연재, 다음 소식 약속) | 팔로우 증가 |

## 내 기준으로 키우기
이 스킬은 받은 사람이 자기 것으로 키우는 복사본입니다. 원본과 합치지 않습니다.
- 처음 쓸 때 판단 기준이 `~/.claude/shortform-review/knowledge/shortform/`에 복사됩니다. 이 사본을 레퍼런스·평가·기획을 하면서 계속 고쳐 키웁니다.
- 스킬을 다시 설치해도 사본, 설정, 레퍼런스는 지워지지 않습니다. 새로 설치된 씨앗은 쓰지 않고 사본만 씁니다.
- 마케팅리드 지식이 바뀌어 다시 받았다면 다음 사용 때 바뀐 부분만 어시스턴트에 더해집니다.
- 키우는 규칙(패턴 승격, 짝 비교, 표기)은 SKILL.md의 "기준 키우기"에 있습니다.

## 폴더 구성
```
shortform-review/
├ SKILL.md              Claude가 따르는 절차
├ README.md             이 문서
├ COLLECT.md            계정 수집·짝 비교 절차
├ scripts/              릴스 다운로드·장면 추출·받아쓰기
├ knowledge/shortform/  처음 한 번 내 사본으로 복사되는 씨앗(목적별 템플릿, 기본기, 엣지, 버릴 것, 평가 기준표, 외부 릴스 분석 근거)
└ marketing-lead/       마케팅 어시스턴트에 흡수시킬 지식 (README, INGEST 절차, MANIFEST 버전표)

~/.claude/shortform-review/      내 PC에만 있음, 업데이트해도 유지
├ config.md                      연결된 마케팅 어시스턴트
├ knowledge/shortform/           내 릴스 판단 기준(씨앗에서 복사, 계속 키움)
├ references/{계정 또는 주제}/    내가 모은 레퍼런스 (reels/ 분석 + 정리.md)
└ accounts/{계정}/               운영 계정별 프로필, 운영 로그, 챌린지
```
