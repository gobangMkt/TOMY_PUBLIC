# shortform-review: 릴스 기획·평가 스킬

인스타 릴스를 기획하거나, 팀원·서포터즈가 만든 릴스를 평가하는 Claude Code 스킬입니다.
사내에서 외부 릴스를 분석해 쌓은 기준(목적별 템플릿, 기본기, 엣지, 버릴 것)과 마케팅 판단 지식(후킹·카피·퍼널·타겟팅)이 함께 들어 있습니다.

## 설치 (한 번만)
Claude Code 채팅창에 아래를 **그대로 붙여넣으면** Claude가 설치부터 도구 준비까지 알아서 합니다.

```
아래 순서대로 진행해줘. 중간에 나한테 묻지 말고 끝까지 해.
1. 터미널에서 `npx skills add gobangMkt/TOMY_PUBLIC --skill shortform-review -g` 실행
2. 설치된 shortform-review 스킬의 SKILL.md를 읽고 "0. 처음 한 번: 도구 설치" 단계 실행 (yt-dlp, ffmpeg, faster-whisper)
3. 다 되면 설치 결과와 내가 쓸 수 있는 요청 예시 3개를 알려줘
```

설치가 끝나면 Claude Code를 한 번 껐다 켜야 스킬이 목록에 뜹니다. `/skills`로 확인할 수 있습니다.

## 쓰는 법
| 하고 싶은 것 | 이렇게 말하면 됩니다 | 받는 것 |
|---|---|---|
| 만든 릴스 평가 | `이 릴스 평가해줘 https://www.instagram.com/reel/XXXX/` (여러 개 가능) | 목적·템플릿 판정, 통과·보완·재작업, 고칠 구간(초)과 방법, 다음에 얹을 엣지 |
| 서포터즈 릴스 일괄 평가 | `서포터즈 릴스들 평가해줘` + 링크 목록 + (알면) 계정별 팔로워·조회수 | 건별 평가 + 공통 문제 표 |
| 릴스 기획 | `OO 마케팅할 건데, 유입 목적 릴스 기획해줘` | 템플릿 1~3개, 초 단위 구간 구성과 문구 초안, 얹을 엣지, 성공 지표 |
| 트렌드 | `요즘 릴스 뭐가 떠?` | 기준에 쌓인 엣지가 언제부터 퍼졌는지 |

조회수·팔로워 수는 링크로는 읽히지 않습니다. 알고 있으면 같이 적어 주세요(예: `조회 3.2만, 팔로워 1.1만`). 없으면 "미확인"으로 평가합니다.

## 목적 세 가지
| 목적 | 노리는 것 | 판단 지표 |
|---|---|---|
| 바이럴 | 조회수가 터지는 것 (공유·저장·반복 재생) | 팔로워 대비 조회수, 공유 |
| 유입 | 인스타 밖으로 넘어오는 것 (댓글 → DM 링크, 프로필 링크, 검색) | 댓글÷좋아요, 링크 클릭 |
| 구독 | 계정을 따라오게 하는 것 (연재, 다음 소식 약속) | 팔로우 증가 |

## 기준이 바뀌면
기준은 원본에서만 쌓입니다. 이 스킬 안의 파일을 직접 고치면 다음 업데이트에서 덮어써집니다.
평가 결과 끝에 나오는 **"기준 갱신 제안"** 칸을 원본 관리자에게 전달해 주세요.

업데이트 받기: Claude Code에서 `! npx skills add gobangMkt/TOMY_PUBLIC --skill shortform-review -g`를 다시 실행하면 됩니다.

## 폴더 구성
```
shortform-review/
├ SKILL.md                  Claude가 따르는 절차
├ README.md                 이 문서
├ scripts/                  릴스 다운로드·장면 추출·받아쓰기
└ knowledge/
  ├ shortform/              목적별 템플릿, 기본기, 엣지, 버릴 것, 평가 기준표, 외부 릴스 분석 원장
  └ marketing/              마케팅 판단 지식 (후킹·카피·퍼널·타겟팅·인스타 콘텐츠 유형)
```
