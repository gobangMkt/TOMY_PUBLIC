# shortform-review: 릴스 기획·평가 스킬

인스타 릴스를 기획하거나, 팀원·서포터즈가 만든 릴스를 평가하는 Claude Code 스킬입니다.
- 릴스 판단 기준: 외부 릴스를 분석해 쌓은 목적별 템플릿, 기본기, 엣지, 버릴 것
- 마케팅 판단: **본인 마케팅 어시스턴트**가 맡습니다. 스킬에 든 마케팅리드 지식(소재·카피·타겟팅·채널·예산·이벤트·상세페이지)을 그 어시스턴트에 더해서 키웁니다.

## 설치 (한 번만)
Claude Code 채팅창에 아래를 **그대로 붙여넣으면** 설치, 도구 준비, 마케팅 어시스턴트 연결까지 Claude가 진행합니다.

```
아래 순서대로 진행해줘.
1. 터미널에서 `npx skills add gobangMkt/TOMY_PUBLIC --skill shortform-review -g` 실행
2. 설치된 shortform-review 스킬의 SKILL.md를 읽고 "0. 처음 한 번: 설치 마무리"를 끝까지 진행
   (도구 설치는 묻지 말고 진행, 마케팅 어시스턴트 위치만 나한테 물어봐)
3. 다 되면 설치 결과, 마케팅 어시스턴트에 더해진 내용, 내가 쓸 수 있는 요청 예시 3개를 알려줘
```

중간에 한 번 **본인 마케팅 어시스턴트가 어디 있는지**(폴더 경로 또는 스킬 이름) 묻습니다. 알려주시면 마케팅리드 지식을 거기에 더합니다. 기존 내용은 지우거나 고치지 않고 덧붙이기만 하고, 겹치거나 기준이 다른 곳은 따로 알려드립니다.

설치 후 Claude Code를 한 번 껐다 켜면 스킬이 뜹니다(`/skills`로 확인).

## 쓰는 법
| 하고 싶은 것 | 이렇게 말하면 됩니다 | 받는 것 |
|---|---|---|
| 만든 릴스 평가 | `이 릴스 평가해줘 https://www.instagram.com/reel/XXXX/ (조회 3.2만, 팔로워 1.1만)` | 목적·템플릿 판정, 통과·보완·재작업, 고칠 구간(초)과 방법, 다음에 얹을 엣지 |
| 서포터즈 릴스 일괄 평가 | `서포터즈 릴스들 평가해줘` + 링크 목록 + (알면) 계정별 팔로워·조회수 | 건별 평가 + 공통 문제 표 |
| 릴스 기획 | `OO 마케팅할 건데, 유입 목적 릴스 기획해줘` | 템플릿 1~3개, 초 단위 구간 구성과 문구 초안, 얹을 엣지, 성공 지표 |
| 트렌드 | `요즘 릴스 뭐가 떠?` | 기준에 쌓인 엣지가 언제부터 퍼졌는지 |
| 어시스턴트 변경 | `마케팅 어시스턴트 다시 지정해줘` | 새 어시스턴트 연결 + 지식 흡수 |

조회수·팔로워 수는 링크로는 안 읽힙니다. 알면 같이 적어 주세요. 없으면 "미확인"으로 평가합니다.

## 목적 세 가지
| 목적 | 노리는 것 | 판단 지표 |
|---|---|---|
| 바이럴 | 조회수가 터지는 것 (공유·저장·반복 재생) | 팔로워 대비 조회수, 공유 |
| 유입 | 인스타 밖으로 넘어오는 것 (댓글 → DM 링크, 프로필 링크, 검색) | 댓글÷좋아요, 링크 클릭 |
| 구독 | 계정을 따라오게 하는 것 (연재, 다음 소식 약속) | 팔로우 증가 |

## 업데이트
`! npx skills add gobangMkt/TOMY_PUBLIC --skill shortform-review -g`를 다시 실행하면 됩니다.
- 마케팅리드 지식이 바뀌었으면 다음 사용 때 바뀐 부분만 어시스턴트에 자동으로 더해집니다.
- 본인 설정(`~/.claude/shortform-review/`)과 어시스턴트 내용은 업데이트해도 그대로입니다.
- 릴스 판단 기준은 원본에서만 쌓입니다. 평가 결과 끝의 **"기준 갱신 제안"** 칸을 원본 관리자에게 전달해 주세요.

## 폴더 구성
```

├ SKILL.md              Claude가 따르는 절차
├ README.md             이 문서
├ scripts/              릴스 다운로드·장면 추출·받아쓰기
├ knowledge/shortform/  목적별 템플릿, 기본기, 엣지, 버릴 것, 평가 기준표, 외부 릴스 분석 근거
└ marketing-lead/       마케팅 어시스턴트에 흡수시킬 지식 (README, INGEST 절차, MANIFEST 버전표)
```
