# 기본기

목적과 상관없이 여러 계정이 흔히 쓰는 것. 해도 차별화가 안 되고, 안 하면 손해다. 인사이트로 올리지 않는다.
목적별 기본 장치(유입의 DM 보상·정보 숨김 등)는 각 목적 파일에 있다.

| 기본기 | 고방 | 근거 |
|---|---|---|
| 첫 화면에 주제를 제목 자막으로 띄운다 | 함 | 거의 모든 사례 |
| 무음으로 봐도 이해되게 자막을 단다 | 함 | 총괄 확정 2026-10-06 |
| 형용사 대신 숫자로 말한다(월 34만원, 10~15초 유지, 35접시) | 함 | 정보형 대부분 |
| 직접 찍은 실물 화면이 중심이다(화면 녹화, 공간 워크스루, 셀카, 손 탑뷰) | **안 함** | 18건. 예외는 카드뉴스·방송 클립·그림 |
| 인물이 나와 실제 써 본 후기·꿀팁으로 들어간 뒤 상품을 설명하고 댓글로 넘긴다 | **안 함** | 총괄 판단 2026-10-08: 이미 흔해졌다. 몽벨, 가전, 자취방, 간편식 |
| 트렌드 음원 | 함 | 총괄 확정 2026-10-06 |
| 밈 스티커로 감정 표현(고양이·강아지) | 함 | 자취방, AI 직원, 고방 전반. 효과 근거 없음, 써도 그만 |

**고방이 안 하는 기본기 2개(실물 화면, 인물 후기형 진입)는 고방 입장에선 빠진 기본기다.** 인사이트가 아니라 먼저 채워야 할 바닥이다.
