# 기본기

목적과 상관없이 여러 계정이 흔히 쓰는 것. 해도 차별화가 안 되고, 안 하면 손해다. 인사이트로 올리지 않는다.
목적별 기본 장치(유입의 DM 보상·정보 숨김 등)는 각 목적 파일에 있다.

| 기본기 | 고방 | 근거 |
|---|---|---|
| 첫 화면에 주제를 제목 자막으로 띄운다 | 함 | 거의 모든 사례 |
| 무음으로 봐도 이해되게 자막을 단다 | 함 | 총괄 확정 2026-10-06 |
| 형용사 대신 숫자로 말한다(월 34만원, 10~15초 유지, 35접시) | 함 | 정보형 대부분 |
| 소재가 시청자 본인의 이득이다(돈, 자격, 손해 방지) | 함 | 경쟁 4개 계정 상위 전부. 반대로 자사 앱 홍보·계정 회고는 같은 계정 중앙값의 절반 이하(집지켜 09-30·10-08, 분양통 10-06) |
| 협찬은 소재가 약하면 약하다(소개형 협찬이 같은 계정 정보형의 1/20~1/300 사례 다수). 협찬 자체는 설명 변수가 아니다: 협찬 4건이 18.2배, 4.8배, 0.33배, 0.11배로 갈렸다 | 해당 없음 | 헬리퀸, 하이윤, 김잔디, 율리. 반례: 부상구 협찬 영상이 같은 계정 정보형의 약 20배 |
| 같은 계정 안에서 조회를 가르는 1순위는 소재의 범위다. 상위는 제도·공고·시세 같은 일반 정보, 하위는 특정 제품·서비스·도구 소개 | 해당 없음 | 짝 비교 4개 그룹 모두에서 같은 방향(그룹마다 3개 안팎 계정). 포맷·요청·출연이 같아도 갈렸다(부운서 같은 목록 포맷 3,899,000 대 82,000~126,000, 부깐 같은 손 오버레이 포맷 6,980,000 대 28,000). 반례: 짠부부 하위 1건은 기한 있는 금융상품인데도 낮음, 모음이 당근절·빗썸은 기한이 있어도 하위. 소재와 협찬 표기가 겹쳐 협찬 자체의 효과는 분리 못 함 |
| 상위 훅은 구체 숫자·종목명·결론으로 시작하고, 하위 훅은 대상 호명("~라면")이나 일반 질문으로 시작하는 경향이 있다 | 확인 필요 | 3개 그룹에서 각 3개 계정이 같은 방향이나 쌍 수가 적어 가설 수준. 반례: 부운서(훅 유형 같음), 모음이 빗썸(결론형인데 하위) |
| 요청(댓글 키워드) 유무·출연·길이는 계정 안 상·하위를 가르지 못한다 | 해당 없음 | 짝 비교에서 거의 전 건이 요청을 갖고 있어 변별 불가 |
| 직접 찍은 실물 화면이 중심이다(화면 녹화, 공간 워크스루, 셀카, 손 탑뷰) | **안 함** | 18건. 예외는 카드뉴스·방송 클립·그림, 공고형 일러스트·지도(1분분양 터진 건 전부) |
| 인물이 나와 실제 써 본 후기·꿀팁으로 들어간 뒤 상품을 설명하고 댓글로 넘긴다 | **안 함** | 총괄 판단 2026-10-08: 이미 흔해졌다. 몽벨, 가전, 자취방, 간편식 |
| 트렌드 음원 | 함 | 총괄 확정 2026-10-06 |
| 밈 스티커로 감정 표현(고양이·강아지) | 함 | 자취방, AI 직원, 고방 전반. 효과 근거 없음, 써도 그만 |

**고방이 안 하는 기본기 2개(실물 화면, 인물 후기형 진입)는 고방 입장에선 빠진 기본기다.** 인사이트가 아니라 먼저 채워야 할 바닥이다.
