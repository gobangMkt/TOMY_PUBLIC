# 릴스 기록 형식 (릴스 원장 1건 = 파일 1개)

파일명: `{게시일 YYYY-MM-DD}_{계정}_{릴스ID}.md`  (게시일순 정렬이 목적)
모든 서술에 `[확인]`(영상·메타에서 직접 본 것) 또는 `[추정]`(해석)을 붙인다.
보이지 않는 것은 "내가 본 프레임에서는"으로 한정한다.

```
# 릴스 {릴스ID}
- 플랫폼 / URL / 계정 / 게시일 / 수신일 / 길이(초) / 좋아요 / 댓글수
- 조회수(프로필 릴스 탭 타일) / 팔로워 / 팔로워 대비 배수 (못 읽으면 미확인)
- 캡션 원문 (그대로)
- 업종·주제 (한 줄)
- 목적: 바이럴·유입·구독 중 1개 / 템플릿: {목적}-{구조} 1개 / 엣지: edges.md 번호 또는 없음  ← shortform/README.md 판정 규칙

## 구간표 (시간순)
| 구간(초) | 화면 | 자막/음성 | 역할(훅·증거·노하우·행동요청 등) |

## 포맷 요소
훅 방식 / 자막 문체·말투 / 편집 속도와 자막 교체 주기 / 화면 구성 / 음성·음악 / 수치·증거 사용 / 기타

## 반응 유도 방식
무엇을 보여주고 무엇을 숨기는가 / 행동요청 위치·길이·형태 / 댓글 상위 내용이 시사하는 것

## 기본기·버릴 것
기본기 사용 여부 한 줄. 버릴 것(expired.md)을 쓰고 있으면 무엇인지.

## 새로 보인 것
기본기·버릴 것·기존 엣지에 없는 방식. 겉모양이 아니라 작동 원리([추정])까지: 시청자의 어떤 행동(재생 반복·완주·저장·공유·팔로우)을 만들고 왜 노출이 늘어나는지. 없으면 "없음".

## 한계
못 본 것·불확실한 것
```
