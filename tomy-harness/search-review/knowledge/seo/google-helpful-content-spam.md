# 구글 도움이 되는 콘텐츠, 스팸 정책, 생성형 AI 콘텐츠

> 마케팅팀장 지식. 글 기획·대량 생산·AI 활용·콘텐츠 품질 점검 시 구글이 허용하는 선을 확인할 때 쓴다. 출처: 구글 검색 센터 공식 문서(URL 하단). 회사 실측 데이터는 담지 않는다.

## 1. 큰 원칙

- 사람을 돕기 위해 만든 콘텐츠여야 한다. 주로 검색엔진 유입을 노린 콘텐츠는 보상받지 못한다 (/creating-helpful-content).
- E-E-A-T(경험, 전문성, 권위, 신뢰성)는 순위 요인이 아니다. 4개 중 가장 중요한 것은 신뢰성이고, 다 갖출 필요는 없다. 건강·금융·안전 같은 주제(YMYL)는 E-E-A-T 높은 콘텐츠에 더 가중치를 둔다.
- 구글은 선호하는 단어 수가 없다. 글 길이는 순위 기준이 아니다 (/seo-starter-guide).
- 변경이 검색에 반영되기까지 몇 시간에서 몇 개월. 효과 판단은 보통 몇 주 기다린다.

## 2. 글 품질 자체 점검 (게시 전/정비 때)

검색엔진 중심 경고 신호. 몇 개라도 "예"면 제작 방식을 재검토한다.
- 주로 검색 유입을 노리고 만든 글인가.
- 검색 성과를 위해 여러 주제에 걸쳐 대량 생산하는가. 광범위한 자동화로 다양한 주제를 찍어내는가.
- 다른 곳 내용을 요약만 하고 가치를 거의 더하지 않는가.
- 인기 주제만 쓰고 기존 독자를 위한 글은 안 쓰는가.
- 읽고 나서 다른 곳에서 더 나은 정보를 찾아야 하는 글인가.
- 전문성 없이 틈새 주제에 들어온 이유가 검색 트래픽인가.
- 답할 수 없는 질문에 답하는 척하는가 (예: 확정되지 않은 출시일).
- 내용 변화 없이 날짜만 바꿨는가.
- 새 사이트처럼 보이려고 대량 추가하거나 오래된 글을 대량 삭제하는가.

사용자 중심 신호. "예"가 많을수록 좋다.
- 기존·의도된 독자가 있는가. 실제 경험과 깊이가 보이는가. 사이트에 명확한 주 목적이 있는가.
- 읽은 사람이 목적을 달성할 만큼 충분히 배웠는가. 만족스러운 경험이었는가.
- 고유한 정보·분석·보고가 있는가. 주제를 빠짐없이 설명하는가. 다른 출처를 쓸 때 복사·단순 재작성을 넘어 가치를 더했는가.
- 제목이 내용을 정확히 요약하며 과장·자극적이지 않은가.
- 맞춤법·문체 문제가 없는가. 급하게 만든 티가 없는가. 검증 가능한 사실 오류가 없는가.

## 3. 콘텐츠 평가 속성

- 노력: 독창적 분석, 직접 번역, 맞춤 기능은 노력이 크다. 자동 생성이나 감독 없는 생성형 AI 대량 텍스트는 노력이 거의 없다고 본다. 출처 표시가 독창적 노력을 대신하지 못한다.
- 독창성: 다른 곳에 없는 정보·관점.
- 정확성: 사실과 맞아야 하고 YMYL은 전문가 합의와 일치해야 한다.
- 누가: 작성자를 명확히 드러낸다. 바이라인, 배경 소개. AI 생성 프로필 사진, 가짜 이름, 허위 자격 증명은 기만이며 낮은 품질 신호다.
- 어떻게: 제품 리뷰라면 테스트 개수·방법·결과를 증거와 함께 보인다.

## 4. 스팸 정책 중 정보 콘텐츠 사이트에 해당하는 것

| 항목 | 한 줄 규칙 |
|---|---|
| 확장된 콘텐츠 악용 | 사용자 가치 없이 독창성 없는 페이지를 대량 생산하면 위반. AI 도구로 대량 생성, 다른 페이지 짜깁기, 여러 사이트에 분산 모두 해당. 제작 방식이 사람이든 AI든 상관없다 |
| 스크래핑 | 남의 콘텐츠를 가져와 가치 추가 없이 게시. 동의어 치환 복사도 포함 |
| 만료된 도메인 악용 | 만료 도메인을 사서 원래와 무관한 낮은 가치 콘텐츠를 올리면 위반 (정부·자선단체 사이트에 제휴 콘텐츠 예). 중고 도메인 인수 시 기존 용도를 이어가는지 점검 |
| 사이트 인지도 악용 | 호스트의 기존 순위 신호를 이용하려고 서드파티 콘텐츠를 올림. 스폰서 콘텐츠를 사이트에 입히는 경우 주의 |
| 빈약한 제휴 페이지 | 고유 콘텐츠 없이 판매자 설명·리뷰를 복사. 가격, 독자 리뷰, 테스트, 비교 같은 가치를 더하면 우수 제휴 페이지 |
| 도어웨이 | 특정 검색어용 거의 같은 페이지를 대량 생성해 최종 페이지로 보냄 |
| 유인 키워드 반복 | 키워드·도시명·번호를 부자연스럽게 채움 |
| 숨겨진 텍스트·링크 | 흰 배경 흰 글씨 등. 아코디언·탭은 허용 |
| 링크 스팸 | 링크 매매, 과도한 상호 링크, 자동 링크. 광고·협찬 링크는 rel="sponsored" 또는 nofollow |
| 클로킹 / 부적절한 리디렉션 | 검색엔진과 사용자에게 다른 내용 / 다른 곳으로 보냄. 정상 이전·통합 리디렉션은 허용 |
| 사용자 생성 스팸 | 댓글·게시판 스팸. 소유자가 막아야 하고 UGC 링크에는 ugc/nofollow |
| 법적 삭제·정책 회피 | 유효한 저작권 삭제 요청이 많으면 사이트 전체 순위 하락 가능. 정책 회피를 위해 새 하위 도메인·사이트를 만들면 사이트 섹션이 더 넓게 제외될 수 있음 |

- 위반 시: 순위 하락 또는 검색결과에서 사라짐. 자동 시스템과 필요시 사람 검토로 판정. 목록에 없는 유형도 조치할 수 있다.
- 해킹된 콘텐츠, 악의적 행위, 머신 생성 트래픽(순위 확인용 스크래핑)은 이 사이트 운영과 접점이 낮아 생략.
- 중복 자체는 스팸이 아니나 대량 복제 목적이면 위 항목에 걸린다.

## 5. 생성형 AI 콘텐츠 규칙

- AI 사용 자체는 금지가 아니다. 단 순위 조작이 주목적인 대량 생성은 스팸 정책 위반이다 (/using-gen-ai-content, /creating-helpful-content).
- 생성 모델은 사실을 검색하는 게 아니라 가능성 높은 단어열을 예측한다. 게시 전 정확성·신뢰성을 사람이 직접 검토한다. title, 메타 설명, 구조화 데이터, 이미지 alt에도 적용.
- 감독·선별 없이 대량 생성된 텍스트는 "노력 거의 없음"으로 평가된다.
- 자동화·AI를 썼다고 독자가 합리적으로 예상할 콘텐츠에는 사용 방식과 이유를 공개하는 문구를 권장한다. 의무 조항이 아니라 권장이다.
- AI 생성 이미지는 IPTC DigitalSourceType TrainedAlgorithmicMedia 메타데이터를 포함해야 한다. 이커머스의 AI 생성 상품 데이터는 별도 지정하고 AI 생성으로 라벨링.
- 검색어 변형마다 페이지를 대량 생성하면 확장된 콘텐츠 악용에 해당한다. 페이지 수가 많다고 품질이 높아지지 않는다.
- 생성형 AI 검색 기능(AI 개요 등)에 노출되려면 색인되어 있어야 하고 별도 특수 최적화는 필요 없다. llms.txt 같은 AI 전용 파일은 구글 검색이 무시한다. 청킹(글 쪼개기), AI용 재작성, 이상적인 페이지 길이는 불필요하다 (/ai-optimization-guide).
- 흔한 주제 글("초보 N가지 팁") 대신 직접 겪은 경험·구체 사례로 차별화하라는 것이 구글의 예시다.

## 6. 적용 체크 (글 수천 개 규모 사이트)

- 시리즈형 대량 발행이라면 "글마다 고유 정보가 들어갔는가"를 기준으로 삼는다. 키워드 변형만 다른 글이 많으면 확장된 콘텐츠 악용과 중복 클러스터링 양쪽 위험이다.
- 외부 정보 요약형 글은 가치 추가(비교, 판단, 직접 확인한 절차)가 없으면 "요약만 하고 가치 없음" 경고에 해당.
- 날짜 갱신은 내용 갱신과 같이 한다.
- 작성자 정보는 실제 담당자 기준으로 쓴다. 가짜 이름·AI 프로필은 금지.
- 페이지 경험(모바일, 광고)도 영향: 광고가 읽기를 방해하거나 콘텐츠를 가리는 인터스티셜은 피한다.

## 7. 외부 SEO 업체·도구 거르는 기준

- 순위 보장, 구글과 특별한 관계라는 주장은 피한다. 구글은 서드파티 도구를 승인하지 않고 도구는 구글 내부 순위 데이터에 접근하지 못한다 (/do-i-need-seo, /third-party-seo).
- 업체 행위의 책임은 사이트 운영자에게 있다. 업체에는 Search Console 읽기 권한만 준다.
