# search-review: 검색 개선 평가·진단 스킬

검색 인사이트 앱이 내보낸 검색 데이터(JSON)를 읽어 **글·검색어마다 평가(시급·나중·관찰·문제 없음)를 붙이고**, 손볼 건을 진단해 제목안과 할 일을 내는 Claude Code 스킬입니다.
- 평가: `scripts/evaluate.py`가 계산합니다. 증상 x 규모(노출)로 가르고, 문턱값은 앱이 내보낸 파일의 `rules`에서 읽습니다. 건수를 더하면 전체와 같습니다(빠지는 글이 없습니다)
- 진단: 구글 검색 센터·Search Console 공식 문서와 SEO 실무 글을 요약한 지식(`knowledge/seo/`)을 근거로 Claude가 씁니다
- 마케팅 판단: **본인 마케팅 어시스턴트**가 맡습니다. 스킬에 든 SEO 지식을 그 어시스턴트에 흡수시켜 키웁니다

## 설치 (한 번만)
Claude Code 채팅창에 아래를 **그대로 붙여넣으면** 설치, 지식 흡수, 마케팅 어시스턴트 연결까지 Claude가 진행합니다.

```
아래 순서대로 진행해줘.
1. 터미널에서 `npx skills add gobangMkt/TOMY_PUBLIC --skill search-review -g` 실행
2. 설치된 search-review 스킬의 SKILL.md를 읽고 "0. 처음 한 번: 설치 마무리"를 끝까지 진행
   (설치는 묻지 말고 진행, 마케팅 어시스턴트 위치만 나한테 물어봐)
3. 다 되면 설치 결과, 마케팅 어시스턴트에 더해진 내용, 내가 쓸 수 있는 요청 예시 3개를 알려줘
```

중간에 한 번 **본인 마케팅 어시스턴트가 어디 있는지**(폴더 경로 또는 스킬 이름) 묻습니다. 릴스 스킬(shortform-review)을 이미 설치했다면 같은 어시스턴트를 쓸지만 확인합니다. 기존 내용은 지우거나 고치지 않고 덧붙이기만 합니다.

설치 후 Claude Code를 한 번 껐다 켜면 스킬이 뜹니다(`/skills`로 확인).

## 쓰는 법
먼저 검색 인사이트 앱의 `검색 현황` 화면에서 **`데이터 내보내기`** 를 눌러 `검색인사이트_날짜.json`을 받습니다.

| 하고 싶은 것 | 이렇게 말하면 됩니다 | 받는 것 |
|---|---|---|
| 평가 | `방금 내보낸 검색 데이터 평가해줘` | 평가별 건수 표 + 시급·나중 상위 건(이유 포함) |
| 진단 | `시급 상위 10건 진단해줘` | 건마다 진단 이름·지표 목표·원인·할 일·제목안(추천도·예상·가설) |
| 요청서 | `진단한 것 요청서로 만들어줘` | 담당자에게 줄 `검색개선요청_날짜.md` |
| 효과 확인 | `4주 전 요청한 건 효과 봐줘` + 새 JSON | 기준 지표와 지금 값 비교(좋아짐·나빠짐·변화 없음) |
| 검색 질문 | `노출이 갑자기 떨어졌을 때 뭐부터 봐?` | 구글 공식 문서 기준 진단 순서 |

## 평가 4단계
| 평가 | 할 일 |
|---|---|
| 시급 | 이번 주 안에 전부 처리 |
| 나중 | 이번 달 안에 처리 |
| 관찰 | 손대지 않고 다음 갱신에서 또 걸리는지 봄 |
| 문제 없음 | 없음 |

## 이 스킬이 하지 않는 것
- 글을 직접 고치지 않습니다. 진단과 요청서까지이고, 고치는 것은 담당자입니다
- 평가 문턱값을 바꾸지 않습니다. 바꾸려면 앱 쪽 설정을 고칩니다
- 근거 없는 수치를 단정하지 않습니다. 구글이 공개하지 않은 기준(몇 주 뒤 개입 등)은 "비공개"라고 말합니다

## 폴더
- `SKILL.md` 스킬 본문 · `scripts/evaluate.py` 평가 계산 · `knowledge/seo/` SEO 지식(씨앗, 설치할 때 내 사본으로 복사)
- 내 사본·설정·기록: `~/.claude/search-review/` (스킬을 업데이트해도 지워지지 않음)

## 업데이트
스킬 업데이트는 같은 설치 명령을 다시 실행합니다. 지식이 바뀌면 다음 사용 때 바뀐 파일만 어시스턴트에 다시 흡수합니다.
