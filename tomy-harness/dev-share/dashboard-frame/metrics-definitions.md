# 고방 지표 정의서 (전사 공유용)

"같은 이름인데 숫자가 다르다"를 끝내기 위한 단일 정의. 어드민 화면·리포트·시트가 모두 이 정의를 따른다.
숫자가 어긋나 보이면 먼저 이 문서에서 정의 차이를 확인한다. 최종 갱신 2026-07-29.

## 1. 기간

| 규칙 | 정의 | 비고 |
|---|---|---|
| **주 경계** | **일요일 ~ 토요일** | 예외 없음. GA4 주(`yearWeek`)도 일요일 시작이라 그대로 맞물린다 |
| **월 경계** | 달력 월 | 주가 달을 걸치면(6.28~7.4) 목표는 **일수 비례로 나눈다** |
| **"전체 기간"** | **최근 365일**(어제까지) | GA4 조회 한계. 연 단위가 아니다 |
| **미완결 기간** | 진행 중인 주·달은 **화면에 그리지 않는다** | 반쪽 실적이면 항상 급락·미달로 보인다 |
| **집계 기준일** | 전일까지 확정. GA4는 최근 3일 소급 변동 가능 | 수집은 3일 rolling 재조회 |

## 2. 트래픽 (GA4)

| 지표 | 정의 | 흔한 오해 |
|---|---|---|
| **활성 사용자** | GA4 `activeUsers` | GA4 홈의 '사용자'는 **총 사용자**(다른 값). |
| **WAU** | 그 주(일~토)의 유니크 활성 사용자 | 일별 합산 금지(유니크 중복). |
| **MAU** | 그 달의 유니크 활성 사용자 | 월 MAU의 합 ≠ 365일 활성(신규 91%라 거의 안 겹침) |
| **스트림별 MAU/WAU** | 웹·안드·iOS 각각의 유니크 | **합 ≠ 총계**(겸용 사용자가 스트림마다 1명씩) → 스택·누적 금지 |
| **채널 구분** | Owned / Paid / Organic / Direct | 소스/매체 → 구분 매핑은 트래픽 원장 `채널_매핑` 탭이 정본(코드 하드코딩 금지) |
| **보존 한계** | GA4 무료 = 14개월 | 22~24년은 API로 조회 불가. 어드민 원장 적재분이 유일 사본 |
| ⚠️ **legacy 구간의 창 정의** | 1시트 백필분(≤2025-06)은 **31일 창**(예: `06.01~07.01`), GA4 적재분(≥2025-07)은 **달력 월** | 두 방식의 월 값이 달라 한 시계열에 섞지 않는다 |
| ⚠️ **반쪽 달 금지** | 조회 창의 **첫 달이 잘렸으면 버린다**(`dropPartialFirstMonth`) | 2026-07-29 사고: 400일 창 시작이 2025-06-23이라 잘린 일부가 전체 달 값을 덮었다 |

## 3. U사장님 / U중개사 지표

| 지표 | 정의 | 주의 |
|---|---|---|
| **지점 조회수 · 지점 문의수** | **U사장님 + U중개사 합** | 화면·평균·스냅샷·차트 전부 이 규칙. 채널별 분리는 출처 도넛·수기보정용 |
| **U중개사 정본** | **`api.u-agent.kr`** (별개 서비스) | u-ceo의 `WESTAY_*` 필드가 아니다. |
| U중개사 데이터 시작 | 2023-09-12 | 그 이전은 서비스 없음 → 0이 아니라 `—`로 표기 |
| **문의율** | 문의 ÷ **조회** | `inquiryRate`(문의÷MAU)와 다르다. 라벨에 분모를 항상 붙인다 |
| **활성사용자당 조회/문의** | 조회 ÷ WAU (비율 아님, **1인당 횟수**) | 예: 30만 ÷ 6.2만 = 5.1회 |
| **판매 건수** | 지점이 광고상품을 산 건수(u-ceo `ADS_COUNT`) | '상품구매수'와 같은 사건. 두 이름을 따로 두지 않는다 |
| **파트너 수** | u-ceo `TOTAL_COUNT` = 유료/제휴 파트너 지점 수. 누적 스냅샷 | **합산 금지**(그 기간 마지막 값). ⚠️ **'지점수'가 아니다** — 2026-07-29 실측: 일별 마지막값 891·989·1371·1621·1667 = 1시트 '파트너 수'와 일치 |
| **지점수(전체 등록)** | 1시트 수기 축 | 자동수집 경로가 없어 **2026-06까지만** 존재. 파트너 수와 다른 축이니 같은 차트에 겹치지 말 것 |

## 4. 매출

| 지표 | 정의 | 주의 |
|---|---|---|
| **매출액** | 부가세 포함 실입금 기준 | 어드민 원장의 `amount` |
| **공급가액** | 매출액 ÷ 1.1 | 5시트·1시트는 공급가액 기준 탭이 섞여 있다 |
| **고방 / U사장님 스코프** | `group` 라벨로 가른다(`UBOSS_GROUP = 'U사장님'`) | 화면에서 필터를 직접 짜지 말고 `scopeItemIds`·`scopeAchievement` 사용(fail-open 금지) |
| **U사장님 달성률 분모** | **애드 단독** | U중개사 연간계약·케어프로는 어드민에 수집 경로가 없어 목표에서 제외. 라벨에 '애드' 필수 |
| **달성률 분모(기간)** | `targetForRange` = 월 목표의 **일수 비례 배분** | 주가 달을 걸치면 걸친 만큼만 |
| **전사 달성률** | **만들지 않는다** | U사장님이 전사의 93%라 합치면 고방 상황이 안 드러난다. 항상 분리 표기 |
| 애드 매출 주 단위 | 토스PG 주차 정산 1행으로 들어와 **톱니처럼 튄다** | 페이스 판단은 월간 단위로 |

## 6. "GA4랑 숫자가 다르다" 체크리스트

1. 기간이 최근 365일인가(전체 기간 = 365일, 연 단위 아님)
2. 주 경계가 일~토인가(월~일이면 값이 달라진다)
3. 활성 사용자와 총 사용자를 혼동하지 않았나
4. 유니크 지표를 쪼개서 합산하지 않았나(스트림·채널 합 ≠ 총계)
5. 미완결 주·달이 섞이지 않았나
