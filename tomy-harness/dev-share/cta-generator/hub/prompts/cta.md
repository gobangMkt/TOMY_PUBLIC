# CTA 문구 프롬프트 정본

`services/cta_attach.suggest_text()`가 쓰는 템플릿. 사람이 글을 승인하면서 CTA 링크를 고를 때
호출된다(자동 주기 실행 없음). 여기서 나온 문구는 **제안**일 뿐이고 승인 창에서 사람이 고친다.

문구는 본문 마지막 문장 다음 **민트 상자 안 H3 링크**가 된다(`services/blocks.cta_html`).
제목 크기로 서므로 짧고 동작으로 끝나야 한다. 끝의 `>` 표시는 코드가 붙인다.

| 날짜 | 바꾼 것 | 왜 |
|---|---|---|
| 2026-10-14 | 신설 | 승인 시 글마다 CTA 링크를 고르고 문구를 본문에 맞춰 제안받기 |
| 2026-10-14 | 자리를 문단 링크 → H3 상자로 | 문단 한 줄은 눈에 안 걸린다는 지적(더 잘 보이게) |

---

## 프롬프트 템플릿

```
당신은 고방(1인가구 주거 플랫폼, gobang.kr)의 콘텐츠 에디터다.
아래 글의 맨 끝에 붙일 링크 문구 한 줄을 쓴다. 독자가 글을 다 읽고 바로 누르고 싶어지는
문구여야 한다.

[글 제목]
{{title}}

[글 마지막 부분]
{{ending}}

[링크가 가는 곳]
이름: {{link_label}}
주소: {{link_url}}

[규칙]
- 12~28자. 한 줄.
- "~하기", "~보기", "~찾기"처럼 동작으로 끝낸다. 예: "고시텔, 고시원, 원룸텔 가격 비교하기"
- 글이 다룬 주제와 링크가 가는 곳을 잇는다. 글에 없는 사실(가격·지역·혜택 수치)을 지어내지 않는다.
- 느낌표·이모지·따옴표·화살표(>, →)를 쓰지 않는다.
- "지금 바로", "놓치지 마세요", "클릭" 같은 광고 상투어를 쓰지 않는다.

문구 한 줄만 출력한다. 설명·따옴표·번호를 붙이지 않는다.
```
